# Inquiry-module

A portfolio archive repository featuring a standalone contact form application titled **"Inquiry Module"**. Created on **August 20, 2026**.

---

## 🛠️ Project Details

This single-file web utility was developed as a dedicated, lightweight contact and messaging interface to handle direct project inquiries and communications following the retirement of the main personal website. Built with vanilla web technologies, it provides a clean, self-hosted communication channel.

* **Project Purpose:** Portfolio Piece / Client Contact Form & Communication Utility
* **Creation Date:** August 20, 2026
* **Live Deployment:** [https://john-ogletree.github.io/inquiry-module/](https://john-ogletree.github.io/inquiry-module/)
* **Architecture:** Zero-dependency, client-side web application

---

## 🔑 Key Features

* **Direct Messaging Interface:** Streamlined form layout designed for quick project inquiries and client communication.
* **Vanilla Implementation:** Developed purely with native HTML, CSS, and JavaScript without external frameworks, third-party form builders, or heavy build steps.
* **Responsive Design:** Polished, mobile-friendly interface ensuring seamless accessibility across all devices.
